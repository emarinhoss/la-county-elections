# LA County election dashboard

Tracks Los Angeles County election results (offices and measures) on a city map, with analysis of how the
county voted. First target: the Nov 3, 2026 general election.

Live map and results: https://emarinhoss.github.io/la-county-elections/. Spec: [docs/specs/00_spec.md](docs/specs/00_spec.md).

Data comes from public sources only. Nothing is shown that was not fetched and recorded in this repo.
